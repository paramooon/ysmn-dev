# YSMN — сайт CGI-студии

Одностраничный иммерсивный сайт в эстетике технического чертежа: светлая тема,
hairline-сетка, corner-brackets и «+»-кресты. В hero — **объёмная буква Y,
собранная из ~22 000 частиц** (three.js + кастомные шейдеры). Объект постоянный:
по скроллу он морфится по секциям — Y → сфера (services, тёплый оттенок) →
wireframe-шелл (about) → кольцо (contact), как на референсе vanlent.dev.

Без сборки и зависимостей: чистые HTML/CSS/JS. three.js, GSAP и Lenis грузятся
с CDN и деградируют без сети (нативный скролл, CSS-reveal, DOM-глиф «Y»).

## Как открыть

- Двойной клик по `index.html`, или
- `python3 -m http.server 8000` в этой папке → <http://localhost:8000>.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | все секции: hero → work → services → about → contact |
| `css/style.css` | светлая тема, hairline-сетка, reveal-анимации, адаптив |
| `js/particles.js` | three.js: буква Y из частиц, морфинг по секциям, мышь, drag, dust |
| `js/main.js` | прелоадер «Y S M N», часы, курсор, карусель кейсов, орбита, слайдер услуг, счётчики, reveal, форма |
| `js/portfolio.js` | данные 11 кейсов (обложки/страницы из portfolio-site) |
| `js/i18n.js` | словарь EN/RU, автодетект, localStorage (`ysmn-lang`) |
| `assets/` | 148 изображений проектов |
| `icons/` | favicon/иконки (глиф «Y», из проекта showreel) |
| `validate.js` | проверка целостности: `node validate.js` |

## Механики (по референсу)

- Прелоадер: буквы Y S M N разлетаются по ширине экрана и собираются в логотип.
- Шапка: логотип в hairline-боксе, EN/RU, **процент суток + время** (МСК).
- Вертикальный rail-навигатор секций справа.
- Кейс-карусель: большой мокап + phone-колонка + описание + **вращающаяся
  орбитальная диаграмма из точек** + миниатюры + стрелки + share (копирует
  ссылку `#case=<id>` — есть deep-link). Клик по кадру — лайтбокс-галерея.
- Services: морф-заголовок «Фотореализм / Физика / Точность», word-flip слайдер
  с чёрной плашкой и прогресс-квадратами, счётчики (99% / 30+ / 8+), цитаты.
- Contact: карточки контактов + форма (собирает mailto), футер.

## Управление 3D-объектом

- Мышь: частицы расступаются у курсора.
- Drag (на пустом месте): вращение с инерцией.
- Секции переключают форму автоматически (IntersectionObserver).

## Проверки и тестовый режим

- `node validate.js` — ассеты, паритет i18n-ключей, ключи проектов.
- `?flat=1` — компактный режим (для полных скриншотов), `?s=work` — переход
  к секции. На проде не мешают.

## Что заменить руками

- Телефон `+7 925 000 00 00` (index.html + `hero.l3` в `js/i18n.js`).
- Цитаты клиентов (`srv.quotes`) — плейсхолдеры, замените на реальные.
- Числа в счётчиках (`data-count`, `statPct`) — при необходимости.

## Заметки

- Шрифты Montserrat + IBM Plex Mono — с Google Fonts, без сети включается
  системный фолбэк (буква Y пересэмплируется по `document.fonts.ready`).
- `prefers-reduced-motion`: статичная Y, без автовращения и репульсии.
- Мобильные: 9 000 частиц, DPR ≤ 1.3, бургер-меню на весь экран.
- Частицы рендерятся тёмно-серыми на светлом фоне (как в референсе: толще
  точки для читаемости на светлом), в services — тёплый оттенок #e2a175.
